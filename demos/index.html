Same family, three renderers.

The sample deliberately contains remarriage, children from two unions, and a single-parent union. The goal is to compare layout quality, design freedom, and implementation weight — not to pick a winner from a toy hierarchy.

Family Chart Genealogy-specific layout with restyled HTML cards. Fastest route to something usable, but its person-centric relation model has known multi-spouse limitations. Vue Flow + ELK Fully custom cards and interactions. Explicit union nodes keep children attached to a specific couple; ELK computes positions. Custom SVG A deliberately tiny renderer showing how little code the visual layer can be if we own the genealogy layout contract ourselves.
