Family Chart Genealogy-specific layout with our custom HTML card. Animation is disabled in this pass to test whether the perceived slowness comes from transitions or from layout/rendering itself. MIT · genealogy-specific ApexTree Very compact SVG tree with polished expand/collapse and customizable HTML node templates. The limitation is structural: nested tree data has only one parent path. light · hierarchy-only treeSpider Lightweight D3/TypeScript renderer with several layouts and a cleaner default aesthetic. It also uses a strict id + parentId hierarchy, so marriage needs a projection hack. MIT · hierarchy-only JSCharting Org Commercial, but technically interesting: it supports multiple parents natively. This demo uses invisible-ish family/union points so children descend from the correct couple. paid · multi-parent DHTMLX Diagram Polished org chart with native partner cards and custom HTML shapes. The partner node cannot itself be a parent, so children are not naturally associated with a specific marriage. GPL / paid · partner UI Vue Flow + ELK Maximum UI freedom and explicit family nodes, but visibly the heaviest engineering stack in this comparison. MIT · custom graph Custom SVG The visual baseline: almost no framework, full card/edge control, but positions are hand-authored.
